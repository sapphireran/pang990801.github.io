# 中国人群脚型数据可视化

Personal GitHub Pages project (2020): an ECharts dashboard of children’s
foot-shape teaching samples, plus a **blueprint workshop** that turns those
already-drawn centimetres into size-system notes, a fitting estimator, and a
printable field sheet.

Live dashboard: `index.html`.

This repository is personal study material. It is not a clinic, not a shoe-size
standard, and not medical advice.

## Open locally

From the repository root so relative script paths resolve:

```bash
python3 -m http.server 4173
```

| URL | What you get |
| --- | --- |
| http://127.0.0.1:4173/ | Original five-panel dashboard |
| http://127.0.0.1:4173/docs/blueprint/ | Size systems, allowance, measurement, appendix |
| http://127.0.0.1:4173/examples/blueprint/ | Converter, fitting, growth atlas, last sketch, field kit |

## Layout

```
index.html                 original dashboard
js/index.js                five mounted chart IIFEs
draw1.js / draw2.js        leftover plantar sketches (not mounted)
docs/blueprint/            reading pages (cyanotype / 工程图)
examples/blueprint/        interactive tools
data/blueprint/            extracted JSON + payload.js
scripts/                   rebuild + verify
```

## Rebuild and check

```bash
python3 scripts/build-blueprint-data.py
python3 scripts/verify-blueprint.py
```

The dashboard y-axis labelled **鞋码** is centimetres of length, not a retail
28 / 29 pair mark. Radar axes are 0–100 scores. The left/right pie “counts”
are generated by a formula in `js/index.js`.
