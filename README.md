# Children’s foot-shape dashboard

Personal GitHub Pages site: [pang990801.github.io](https://pang990801.github.io/).

This repository is a **static visualisation** of Chinese children’s foot measurements (height vs shoe size / foot length, age vs foot length, BMI vs plumpness, left–right size mix, and a 9–12 year radar profile). It is a personal / academic sketch, not a product.

Live pages:

| Page | What it is |
| --- | --- |
| [`index.html`](index.html) | Original full-screen dashboard (ECharts + jQuery) |
| [`docs/index.html`](docs/index.html) | Readable notes: charts, data fields, caveats, how to preview locally |
| [`examples/index.html`](examples/index.html) | One-chart-at-a-time gallery, driven by JSON under `examples/data/` |

## Repository layout

```
index.html              dashboard shell
css/                    dashboard styles (index.css compiled from index.less)
js/index.js             five ECharts instances (scatter, bars, line+rings, pie timeline, radar)
js/echarts*.js          vendored ECharts
draw1.js / draw2.js     unused adult plantar sketches (now also standalone examples)
examples/data/*.json    datasets copied out of the charts
examples/*.html         isolated recreations of each chart
docs/                   human-readable notes
```

## Charts on the dashboard

1. **Height × shoe size** — scatter of 199 girls and 199 boys. Pearson *r* ≈ 0.91 in both groups (see `examples/data/height-shoe-summary.json`).
2. **Age × foot length** — mean lengths for ages 6–14, plus girl−boy difference.
3. **BMI × plumpness** — line chart of length/width-style index with two decorative ring charts.
4. **Left / right mix** — autoplay pie over ages 2–14. The slices are generated by a log formula in `js/index.js`, not a raw contingency table.
5. **Radar** — 9–12 year relative indices for height, three girths, shoe size, foot length, and weight. This instance mounts on `.map .chart` (the centre column).

`draw1.js` (plantar pressure) and `draw2.js` (subcutaneous thickness) are **not** loaded by `index.html`. They live as examples now.

## Preview locally

GitHub Pages serves the repo root. For a clone:

```bash
python3 -m http.server 4173
```

Then open:

- http://localhost:4173/
- http://localhost:4173/docs/
- http://localhost:4173/examples/

`fetch()` of the JSON datasets needs http(s), not `file://`.

More detail: [`docs/local-preview.md`](docs/local-preview.md).

## Data honesty

Numbers on the dashboard were transcribed from the original `js/index.js` series. They should be treated as **sample visualisations**:

- Y values labelled 鞋码 are centimetres of foot length in the scatter tooltip.
- The BMI ring-chart counts (50 / 180 and 435 / 2400) are decorative.
- The bilateral pie uses `Math.log` to synthesise slice sizes.
- Adult diabetic-foot sketches in `draw1.js` / `draw2.js` are a separate motif and are not the children’s dashboard.

Field-level notes: [`docs/data-dictionary.md`](docs/data-dictionary.md).
