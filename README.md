# 中国人群脚型数据可视化

Personal GitHub Pages project: a 2020 ECharts dashboard of children’s foot-shape teaching samples, plus a **companion studio** of notes, alternative encodings, and a reading workbook.

Live dashboard (when Pages is pointed at this branch): open `index.html`.

This repository is personal study material. It is not a clinic, not a shoe-size standard, and not medical advice.

## Open locally

From the repository root so relative script paths resolve:

```bash
python3 -m http.server 4173
```

Then visit:

| URL | What you get |
| --- | --- |
| http://127.0.0.1:4173/ | Original five-panel dashboard |
| http://127.0.0.1:4173/docs/ | Companion notes (diary, landmarks, how to read) |
| http://127.0.0.1:4173/examples/ | Encoding studio, workbook, annotated tour |

## Layout

```
index.html                 original dashboard
js/index.js                five mounted chart IIFEs
draw1.js / draw2.js        leftover plantar sketches (not mounted)
docs/                      companion notes
examples/encodings/        same series, different chart types
examples/workbook/         reading practice + worked calculations
examples/tour/             panel-by-panel annotated walkthrough
data/companion/            extracted JSON used by the studio
scripts/                   extract + verify
```

## Rebuild the companion payload

```bash
python3 scripts/extract-companion-data.py
python3 scripts/verify-companion.py
```

## Honesty

Scatter points, age means, BMI traces, and radar scores are copied from the published dashboard. The left/right pie counts are generated by `Math.log` in `js/index.js`, not measured pair by pair. The pressure and thickness files were never wired into `index.html`.
