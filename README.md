# 中国儿童脚型数据可视化

个人 GitHub Pages 项目：用 ECharts 把一组儿童脚型测量结果做成可浏览的大屏。

线上入口：[pang990801.github.io](https://pang990801.github.io/)

这是个人学习与展示仓库。页面里的数字来自当时整理进图表的测量结果，用来看趋势和关系，不是诊疗工具，也不能当成现行国家标准。

## 大屏里有什么

首页 `index.html` 是一张固定布局的可视化大屏，五个图分担不同问题：

| 面板 | 问题 | 实现 |
| --- | --- | --- |
| 身高 × 鞋码 | 身高增加时鞋码怎么走 | 男女散点，带最大/最小/均值标注 |
| 年龄 × 脚长 | 6–14 岁脚长怎么长 | 立体柱 + 男女差值折线 |
| 雷达图 | 9–12 岁几项围度和体型怎么一起变 | 七维雷达 |
| BMI × 胖瘦度 | BMI 和脚长/脚宽比是否同向 | 双折线 + 过胖/过瘦占比环 |
| 双脚比例 | 左右脚是否接近 | 按年龄自动播放的饼图 |

更细的字段、单位和读图方式写在 [`docs/`](docs/README.md)。单独拆开的可运行图在 [`examples/`](examples/index.html)。

## 本地打开

仓库是静态站点，不需要构建：

```bash
python3 -m http.server 4173
```

然后打开：

- 大屏：<http://127.0.0.1:4173/>
- 文档首页：<http://127.0.0.1:4173/docs/>
- 图表示例：<http://127.0.0.1:4173/examples/>

更完整的预览说明见 [docs/local-preview.md](docs/local-preview.md)。
