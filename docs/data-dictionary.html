Fields and units

数据字典

JSON 放在 /data。性别键统一为 female / male，中文界面再写成女生 / 男生。 校验脚本：node scripts/validate-data.js。

height-shoe-size.json

路径类型含义
series.female.points[].heightnumber身高，厘米。范围约 79.7–152.8。
series.female.points[].shoeLengthnumber鞋长 / 脚长标码，厘米。范围约 10.1–24.2。
series.*.fit.slopenumber鞋长对身高的 OLS 斜率。
series.*.fit.interceptnumberOLS 截距，厘米。
series.*.fit.r2number决定系数，女生 0.8345，男生 0.8384。

age-foot-length.json

路径类型含义
ages[]int6 到 14 岁，步长 1 年。
series.female[]number该年龄女生脚长均值，厘米。
series.male[]number该年龄男生脚长均值，厘米。
differenceFemaleMinusMale[]number女减男，厘米。11 岁起为负。

bmi-foot-plumpness.json

路径类型含义
bmi[]int12 到 24。
series.female[] / male[]number项目自定义胖瘦指数，约 23–30。
shareEstimates.narrowFootShareobject过瘦脚示意环：50 / 180。
shareEstimates.wideFootShareobject过胖脚示意环：435 / 2400。

foot-symmetry.json

每个年龄一行。counts 五类相加等于 total。

键中文标签
same双脚相同
leftLarger10to20左脚比右脚大 10–20%
leftLargerOver20左脚比右脚大 20% 以上
rightLargerOver20右脚比左脚大 20% 以上
rightLarger10to20右脚比左脚大 10–20%
 
leftLarger10to20  = round(36 - 13 * ln(i+1))
leftLargerOver20  = round(17 - 6  * ln(i+1))
rightLargerOver20 = round(11 - 4  * ln(i+1))
rightLarger10to20 = round(27 - 10 * ln(i+1))
same              = 63 + a + b + c + d
i = 0 表示 2 岁，i = 12 表示 14 岁

age-radar-profiles.json

indicators 顺序固定，与 values[7] 对齐。分值 0–100。 12 岁鞋长、脚长在原稿里写成 77-6、79-8，JSON 存成 71、71。

plantar-pressure.json / tissue-thickness.json

  • 压力：7 个位点，单位 Pa。两条线 typicalAdult、diabeticFoot。
  • 厚度：14 个位点。柱为 mm，差值序列按原稿标成 um。
  • 位点没有解剖对照表，不要自行命名为“足跟”“第一跖骨”。
