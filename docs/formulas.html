环图百分比

p = v / (v + 占位)。过瘦 50/230 = 21.74%，过胖 435/2835 = 15.34%。这四个数是写死的，不是折线点数出来的。

左右脚时间轴

i = 0…12          # 2岁…14岁
a = round(36 − 13 ln(i+1))
b = round(17 −  6 ln(i+1))
c = round(11 −  4 ln(i+1))
d = round(27 − 10 ln(i+1))
same = 63 + a + b + c + d

2 岁：相同 154 / 245 = 62.86%。14 岁：70 / 77 = 90.91%。相同占比随年龄升高，是因为四个对数项在衰减。
