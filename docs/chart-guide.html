读图与复用

大屏五张图在 js/index.js 的独立 IIFE 里。示例页把数据和 option 拆开，只开一张图也能改。

共用

大屏多数 echarts.init(el, 'dark')。缩放用 bindChartResize(chart)。大屏选择器写死 class；示例页统一 #chart。

chart-helpers.js：createChart、bindChartResize、mountNotes、fmt、linearGradient。

五张图

  1. 散点 — [heightCm, shoeCm]，带 brush / dataZoom。改 exampleData.heightShoe。
  2. 脚长柱 — 每组 bar + 菱形 pictorialBar，差值走第二 Y 轴。改柱宽时菱形 offset 一起改。
  3. BMI 折线 — 右侧环是独立 pie，改折线不会自动改环。
  4. 对称饼 — timeline + options[]。重算用 buildSymmetryByAge()。
  5. 雷达 — 七轴 0–100。大屏 radius: 255 在单页会裁切，示例里按容器缩小。myMap.js 是另一套草稿，已从大屏注释掉。

拷回大屏

在示例页调好 option，把 series.data 写回对应 IIFE，核.bar / .line / .bar1 / .line1 / .map。不要把示例的 px 高度和 flexible.js 的 rem 混用。
