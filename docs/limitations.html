范围与局限

这是个人 GitHub Pages 练习，用来练 ECharts 大屏和把数组拆成文档。 它不是抽样调查，也不是制鞋或儿科的参考值表。

不要用这里的预测鞋码给孩子买鞋，也不要把压力 / 厚度草稿当成糖尿病足筛查材料。 需要真实决策时，用有抽样框、有测量协议的公开数据或临床检查。

已知的数据问题

  • 散点没有地区、测量年份、仪器型号，也没有左右脚标记。
  • 年龄–脚长在 8→9 岁下降，未做质控说明，可能是分组人数不均，也可能是录入如此。
  • 胖瘦指数的名称和数值对不上常见长宽比。
  • 过瘦 / 过胖环图用占位切片凑百分比，与左侧折线没有公式关系。
  • 左右脚五类份额由 Math.log 生成，不是观测频率。
  • 雷达分为相对分；12 岁两项在源码里是减法表达式。
  • 压力位点无解剖对照；厚度差值单位与柱状单位不一致。

页面和技术债

  • 总览 index.html 的 <title> 仍是 Document；导航链到外站和其他同学的 GitHub Pages。
  • 同时引入 echarts.js 和 echarts.min.js，体积重复。
  • CSS 引用了不存在的 液晶数字.TTF，实际只用 DS-DIGIT.TTF。
  • draw1.js / draw2.js 以前没有 HTML 宿主，option 写在全局变量上。

这次文档改动故意没做的事

没有改总览五张图的视觉，也没有“修正” 8–9 岁回落或环图占位算法。 目标是把已经存在的数讲清楚，并给草稿图一个能打开的示例页。 若以后要重做统计，应另开数据集，而不是在这些 JSON 上假装提高精度。
