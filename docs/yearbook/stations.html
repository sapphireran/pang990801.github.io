年龄序列怎么读

How the age series is stored

源码同时写了女、男两组柱和一条“女−男”面积线。年鉴重算差值，与源码数组一致，交叉点在 11 岁。

The source stores girl bars, boy bars, and a girl-minus-boy area. The yearbook recomputes the gap; it matches the source array and crosses at 11.

对称性公式

Symmetry formula

对年龄下标 i（2 岁为 0）：左大 10–20% = round(36−13ln(i+1))，左大 20%+ = round(17−6ln(i+1))，右大 20%+ = round(11−4ln(i+1))，右大 10–20% = round(27−10ln(i+1))，相同 = 63 + 四者之合。

For age index i (age 2 → 0): left +10–20% = round(36−13ln(i+1)), left +20%+ = round(17−6ln(i+1)), right +20%+ = round(11−4ln(i+1)), right +10–20% = round(27−10ln(i+1)), same = 63 + the four bins.
