- [Reading](reading.html) — what to look at first on each panel
- [Provenance](provenance.html) — live files vs leftover sketches
- [Annex](annex.html) — `draw1.js`, `draw2.js`, and the unused China map
- [Hosting](hosting.html) — local preview and GitHub Pages notes
- [Glossary](glossary.html) — bilingual terms used on the dashboard
