这三份遗稿都还在个人仓库里，但首页没有执行它们。附页把内容写清楚，并链到单独的复原示例，避免有人以为儿童仪表盘里画了糖尿病足或航线。

These three leftovers still live in the personal repo, but the homepage never runs them. The annex writes down what they contain and links to standalone reconstructions so nobody mistakes diabetic-foot sketches or flight lines for the children’s dashboard.

Plantar pressure sketch (Pa)

七个位点。正常人序列 90, 50, 39, 50, 120, 82, 80；糖尿病足序列 290, 200, 20, 132, 15, 200, 90。右侧环图用 335 / 180 做占位。图例里还有一个未配序列的“潍V”。

Seven sites. Typical series 90, 50, 39, 50, 120, 82, 80; diabetic-foot series 290, 200, 20, 132, 15, 200, 90. The ring uses 335 / 180 as a placeholder. The legend also names “潍V”, which has no series.

china.js + myMap.js

航线地图草图

Flight-line map sketch

首页里这两行被注释掉了。中央面板的宿主选择器 .map .chart 后来改挂雷达。myMap.js 仍画西安、西宁、拉萨出发的示意航线，城市坐标表在文件前半。示例页用独立宿主复原，避免和雷达抢同一个 DOM。

Both script tags are commented out on the homepage. The .map .chart host later received the radar. myMap.js still describes illustrative routes from Xi’an, Xining, and Lhasa; the city table is the first half of the file. The example uses its own host so it does not fight the radar for the same DOM node.
