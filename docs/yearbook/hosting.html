本机起一个静态站

Serve the tree locally

原仪表盘大多能直接用 file:// 打开。年鉴示例把数据写进 payload.js，同样不依赖 fetch。地图附页要加载 js/china.js，用一个本地静态服务器更稳：

The original dashboard mostly works from file://. Yearbook examples embed payload.js, so they also do not need fetch. The map annex loads js/china.js; a local static server is the more reliable path:

python3 -m http.server 4173
# dashboard:  http://127.0.0.1:4173/
# yearbook:   http://127.0.0.1:4173/docs/yearbook/
# examples:   http://127.0.0.1:4173/examples/yearbook/
