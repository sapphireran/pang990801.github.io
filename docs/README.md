# Documentation

These notes describe the personal children's foot-shape dashboard in this repository. They are written for a future self who wants to reopen a chart, change a series, or lift a panel into a new page without rereading `js/index.js` from the top.

Start here:

1. [Browseable hub](index.html) if you are on GitHub Pages — cards open `read.html?f=…` so the notes render instead of dumping raw Markdown
2. [Architecture](architecture.md) — how the homepage is wired
3. [Chart catalog](charts.md) — one card per visualization
4. [Data dictionary](data-dictionary.md) — field names, units, file locations
5. [Styling](styling.md) — rem units, panel chrome, color tokens
6. [Measurement notes](measurement-notes.md) — what the numbers mean, and the limits
7. [Examples guide](examples-guide.md) — how the standalone pages load JSON

Related folders:

- `../examples/` — runnable pages
- `../examples/data/` — JSON extracted from the original option objects
