这一版多出来的东西

  • 从原脚本抽出的 JSON / payload.js，带源文件 SHA-256。
  • 对 398 个散点做的 OLS、残差分箱、身高分位。
  • 年龄交叉点、装饰环真正的分数、雷达源码里的 77-6 / 79-8。
  • 七张误读卡片，文档和课桌共用同一份 clinic.json。
  • 把 draw1 / draw2 第一次挂到能看见的页面上，但仍标成底稿。
  • 一张可以打印的测站卡片，只抄原图用过的词。

这一版故意没有的东西

  • 新的测量、新的孩子、新的 millimetre。
  • Mondopoint / EU / 英国码 / 美国码换算表。
  • 楦型加放、鞋楦曲线、工厂公差。
  • 对糖尿病足或畸形足的解释。
  • 对 scuscientia / ytep-zhi 同学站的改写。
原 index.html 的五张图仍按 2020 年的配置运行。夜读只在导航上加了两个入口。

如何核对

python3 scripts/extract-desk.py
python3 scripts/verify-desk.py

抽取脚本重写 JSON；校验脚本再跑一遍抽取，并确认 199/199、交叉年龄 11、雷达 71/71、以及夜读/课桌页面都还在。
