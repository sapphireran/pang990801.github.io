# Night Desk docs

A personal second-edition reading room for the 2020 foot-shape dashboard. Open `index.html` through a local static server (see `hosting.html`).

Pages:

- `origin.html` — how `index.html` is wired
- `stations.html` — measurement words the panels actually use
- `reading.html` — how to read each live chart
- `clinic.html` — seven misreads the original page invites
- `leftovers.html` — `draw1.js`, `draw2.js`, `china.js`, `myMap.js`
- `reprint.html` — what this desk adds and what it refuses to add
- `hosting.html` — local preview
- `print-card.html` — a one-page measurement card for paper
