一条命令

python3 -m http.server 4173

在仓库根目录执行，然后打开：

  • /index.html — 2020 仪表盘
  • /docs/desk/index.html — 夜读首页
  • /examples/desk/index.html — 课桌示例

为什么还要服务器

原仪表盘用相对路径加载 CSS/JS，file:// 通常也能看。夜读的误读所和若干示例从 ../../data/desk/payload.js 读数，用 HTTP 更省事，也和 GitHub Pages 的行为一致。

飞线底稿还要加载 js/china.js（约 139 KB）和 js/myMap.js。如果中央雷达页已经打开，不要把同一套 class 再留给地图——附录页用自己的容器。
