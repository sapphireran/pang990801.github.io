这张桌子上有什么

原站只有一页：四张侧栏图，中间一张雷达，标题是「中国人群脚型数据可视化」。draw1.js 和 draw2.js 写了成年足压和皮厚，却从没挂上。china.js / myMap.js 也还在仓库里睡觉。夜读不改那张旧图的算法，只把已经写死的数列抽出来，写成可以引用的笔记和可以点开的课桌。
