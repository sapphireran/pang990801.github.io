个人文档：怎么读这些图，怎么改这些数

这是 GitHub Pages 上的个人学习仓库，不是产品手册。下面的笔记对着现有的五个驾驶舱面板和两份根目录草稿写成，方便以后把一张图单独拆出来，或把数组改成 JSON 再画一次。

结构

Architecture

页面角色、脚本加载顺序、IIFE 图表模块，以及 china.js / draw1.js 这些没挂上首页的文件为什么还留着。

图册

Chart catalog

散点、年龄柱、雷达、BMI 组合图、左右脚时间轴，加上足底压力和软组织厚度两份草稿的读法。

字段

Data dictionary

八个 JSON 的键、单位和条数。散点 199×2，对称饼是公式生成的，不要当成普查。

视觉

Styling

驾驶舱 rem / Less 漂移，以及文档和示例为什么单独写了一套深蓝样式。

测量

Measurement notes

位点没有解剖名、雷达是 0–100 相对分、厚度差值不是两根柱相减。截图前先看这一页。

示例

Examples guide

独立页怎么 fetch JSON、FootTheme.mount 做什么，以及 file:// 打不开的原因。
