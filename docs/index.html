这个站点在画什么

根目录的大屏是一组儿童脚型关系图：身高和鞋长、年龄和脚长、BMI 和脚的胖瘦观感、左右脚是否一样大，以及 9–12 岁的体型围长画像。 这一目录把原来堆在 js/index.js 里的数组拆成可复用的 JSON，并补上读图说明和独立示例页。

怎么走

测量与读图

鞋长、围长、BMI 和“胖瘦度”在这个项目里分别代表什么，以及中国童鞋楦常用的几个围度名称。

数据字典

每个 JSON 字段的单位、取值范围，以及雷达图 0–100 分是怎么来的。

图表说明

总览五张图各自在回答什么问题，坐标轴容易误读的地方标出来。

范围与局限

这些数来自个人可视化练习，不是公开流行病学报告。使用前先看这一页。
