个人可视化说明

这是 2020 年做的个人 GitHub Pages 大屏：用 ECharts 看儿童脚长、鞋码、BMI 和左右脚是否同码。 原来几乎没有说明，数组全写在 js/index.js 里。这组页面把图、数据和生成方式拆开，方便以后改。

测量与读图

每张图在回答什么问题，轴的单位是什么，哪些系列是均值、哪些是生成值。

数据字典

七个 JSON 文件的字段、条数和从原 option 里抽出来的摘要。

图目录

首页四宫格 + 中央雷达，以及从未挂上首页的两张成人对照图。

可运行示例

每张图一页，读取同一份 JSON，用 js/charts/options.js 绘图。

仓库怎么长

路径用途
index.html原来的深色大屏，仍是 GitHub Pages 首页。
js/index.js首页五张图的原始 option，暂时保持原样以免改掉线上效果。
data/*.json从原始 option 抽出的数据集，供说明和示例共用。
docs/本说明站点。
examples/单图示例。
draw1.js / draw2.js成人足底压力和皮下厚度草稿，现已接到示例页。

不要把它当成什么
