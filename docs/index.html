What this folder is

A personal reading layer on top of pang990801.github.io. The dashboard already draws the charts. These notes name the fields, units, and leftover gallery files so a later edit does not have to reverse-engineer js/index.js.

What this folder is not

Not a clinic protocol, not a sizing guide, and not company code. Numbers on this site are illustrative series used to practice ECharts layout. Do not fit shoes from them.
