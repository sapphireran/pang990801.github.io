Personal companion

脚型可视化伴读

这是 2020 年个人 GitHub Pages 仪表盘的阅读本，不是第二套业务系统。 原站把儿童身高、鞋长、年龄、BMI 和左右脚比例画在同一屏；这里把同一串数字拆开讲清楚。

个人学习材料 非临床 非购鞋标准 398 个散点

先读什么

想知道这五个图各自在说什么，从读图笔记开始。想知道雷达图上的围长到底量哪里，看测量地标。

仓库里每个文件当初干什么、哪些脚本其实没挂上，写在档案和项目日记。

再动手

图解工作室用同一份序列改成密度图、坡度图、平行坐标和哑铃图，避免只记得一种 ECharts 皮肤。

练习核对交叉年龄、相关系数和对称饼图的生成式；导览按面板走一遍原仪表盘。

和原仪表盘的关系

伴读不改 js/index.js 里的画图逻辑。数字从个人页面源码抽出，放在 data/companion/。左右脚饼图仍是 Math.log 生成的示意计数； draw1.js / draw2.js 仍是未挂载草稿。

不要用这些点去给孩子买鞋、筛查畸形足或糖尿病足。它们是教学样本，带有展示用的 0–100 分数、占位环和单位不一致的草稿。
