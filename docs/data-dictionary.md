# Data dictionary

All files live under [`data/`](../data/). They are generated by
[`scripts/extract_data.py`](../scripts/extract_data.py) from the 2020
chart scripts. Do not hand-edit JSON unless you also update the
script or stop treating the dashboard as canonical.

`catalog.json` lists the seven datasets and the personal-archive
disclaimer.

## Shared conventions

- Encoding: UTF-8, JSON, 2-space indent, trailing newline.
- Chinese titles are stored as `title_zh` next to an English `title`.
- `source_file` is the script the extract reader parsed.
- Numeric types follow the JS source (ints stay ints when the literal
  had no decimal).
- Missing clinical metadata (sampling city, instrument, date, IRB,
  inclusion rules) is **not invented**. If a field is absent, it was
  never in the repo.

## `height-shoe-size.json`

| Path | Meaning |
| --- | --- |
| `series.female.points` | `[height_cm, shoe_last_cm]`, n = 199 |
| `series.male.points` | same shape, n = 199 |
| `series.*.stats` | min / max / mean / sample stdev, Pearson r, OLS |

`shoe_last_cm` is the Y value the dashboard calls 鞋码. Observed
range is about 9.7–24.4 cm, which matches a foot length, not a
Mondopoint size (180–250) and not EU sizing.

OLS is ordinary least squares of `shoe_last_cm` on `height_cm` with
an intercept. RMSE is `sqrt(mean(residual²))`. R² is 1 − SSE / SST.

Height range in the file: girls 79.73–152.78 cm, boys 75.48–149.96 cm.

## `age-foot-length.json`

| Field | Meaning |
| --- | --- |
| `ages` | 6 … 14 (years) |
| `female_cm` / `male_cm` | mean foot length |
| `female_minus_male_cm` | must equal `female_cm[i] - male_cm[i]` |

Validator asserts that identity. The extract copies the three arrays
independently from `js/index.js`, so a future edit that breaks the
identity will fail CI-less `validate_data.py`.

## `bmi-foot-ratio.json`

| Field | Meaning |
| --- | --- |
| `bmi` | 12 … 24 inclusive |
| `female_ratio` / `male_ratio` | 脚长 / 脚宽 as charted |
| `ring_charts.thin_feet` | 50 vs 180 remainder |
| `ring_charts.plump_feet` | 435 vs 2400 remainder |

## `growth-radar.json`

| Field | Meaning |
| --- | --- |
| `axes` | 身高, 兜跟围长, 跗骨围长, 跖趾围长, 鞋码, 脚长, 体重 |
| `axes_en` | English keys in the same order |
| `series["9岁"…"12岁"]` | seven numbers on a 0–100 index |

12-year shoe last and foot length are the **evaluated** `77-6` and
`79-8` (both 71). If you re-extract after changing those literals,
the validator expects 71 until you edit the assertion.

## `bilateral-symmetry.json`

| Field | Meaning |
| --- | --- |
| `formula` | the four log terms from `js/index.js` |
| `points[]` | one object per age 2–14 |
| `points[].same` | 63 + a + b + c + d |
| `points[].left_10_20` | a |
| `points[].left_over_20` | b |
| `points[].right_over_20` | c |
| `points[].right_10_20` | d |

This is a generative model, not a sample. The `model` string on the
file says so.

## Field units cheat sheet

| Concept | Unit in this archive | Do not confuse with |
| --- | --- | --- |
| Height | cm | — |
| Shoe last on scatter | cm | Mondopoint (mm), EU size |
| Mean foot length | cm | — |
| BMI | kg/m² (bin labels only) | — |
| Plumpness | length / width (ratio × 1) | percent fat |
| Radar axes | 0–100 index | mm or cm |
| Plantar pressure | Pa (label) | kPa / N |
| Soft tissue | mm | the um difference line |
| Bilateral slices | synthetic counts | percent of a surveyed n |

## What is not in the files

- Subject IDs, dates, cities, or device serials
- Left/right raw lengths for the pie (only the log model)
- A mapping from 位点 index → anatomy
- Confidence intervals
- Train / test splits (OLS is descriptive, in-sample)
