选择器为什么对不上图种

类名还停在更早的模板：.bar 实际是散点，.line 实际是柱 + 线， .map 实际是雷达，.bar1 是折线，.line1 是时间轴饼图。 说明和示例按数据 id 命名，不再沿用这些历史类名，以免继续叫错。

首页脚本加载顺序

index.html 依次引入 flexible、jQuery、完整版 echarts、压缩版 echarts、 js/index.js 和 js/click.js。china.js / myMap.js 已注释，所以中央区域不会画航线图。macarons.js 在 <head> 里， 但实例初始化用的是 'dark' 主题而不是 macarons。

示例页只加载 echarts.min.js，不再重复引入完整版，也不再依赖 jQuery。
