项目说明

大屏标题写的是「中国人群脚型数据可视化」，主视图是儿童脚型。导航里的首页、病足页是当时课程站点的外链，源码不在本仓库。

这一页在干什么

把已经收进 js/index.js 的测量结果摊开，同时看身高、年龄、BMI 和左右脚差异。布局是常见数据大屏：顶栏时钟、三列面板、中间一张更大的雷达图。

适合看儿童期脚长、鞋码、围度是不是一起涨，或把单图拆到 examples/ 里改配置。不适合给某个孩子选鞋，也不当作全国普查或现行鞋号国标。

页面骨架

  1. 顶栏：标题 + 本地时钟
  2. 导航：外链首页 / 本页 / 病足页 / mailto
  3. 三列 section.mainbox：左散点与脚长，中雷达，右 BMI 与双脚比例

图表容器是 .panel .chart 或 .map .chart。js/index.js 用写死的选择器 echarts.init。新面板要同时改 HTML 和对应 IIFE。

脚本顺序：flexible.js（rem）→ jQuery → ECharts（完整版 + min，历史原因两份都在）→ index.js → click.js。示例页只引 min 版。

draw1.js、draw2.js 是足底草图，没挂到大屏；示例馆有一页把它们画出来。
