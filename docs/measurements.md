# Measurement names

The dashboard labels are Chinese. This glossary is only for the axis
text that already appears in `js/index.js` and the two draft files.

| Label | How this project uses it |
| --- | --- |
| 身高 | Stature in centimeters. Scatter x-axis; also a radar spoke. |
| 鞋码 | Plotted in **centimeters** (shoe last / shoe length), not EU or US size numbers. Scatter y-axis; also a radar spoke. |
| 脚长 | Foot length in centimeters on the age bar chart. On the radar it is a 0–100 scaled spoke, not raw cm. |
| BMI | Integer body-mass index 12–24 on the plumpness chart. No height/weight pair is stored for that panel. |
| 脚胖瘦度 | Y-axis title says `脚长/脚宽`. Stored values are ~23–30, so read them as a **display index**, not a raw ratio. |
| 脚长/脚宽 | The parenthetical on the plumpness y-axis. A true length÷width ratio for these ages would be closer to 2–3. |
| 兜跟围长 | Heel / around-heel girth. Radar spoke only, scaled 0–100. |
| 跗骨围长 | Tarsal girth (midfoot circumference). Radar spoke only, scaled 0–100. |
| 跖趾围长 | Metatarsophalangeal girth (ball of the foot). Radar spoke only, scaled 0–100. |
| 体重 | Body mass. Radar spoke only, scaled 0–100. |
| 双脚相同 | Timeline-pie slice: left and right categorized as the same. |
| 左脚比右脚大10-20% | Timeline-pie slice generated by `36 - 13 * ln(i+1)`. |
| 左脚比右脚大20%以上 | Timeline-pie slice generated by `17 - 6 * ln(i+1)`. |
| 右脚比左脚大20%以上 | Timeline-pie slice generated by `11 - 4 * ln(i+1)`. |
| 右脚比左脚大10-20% | Timeline-pie slice generated by `27 - 10 * ln(i+1)`. |
| 过瘦脚占比 | Decorative ring. Highlighted 50 vs placeholder 180. |
| 过胖脚占比 | Decorative ring. Highlighted 435 vs placeholder 2400. |
| 位点 | Numbered plantar site on the unpublished sketches (`位点一` … or `位点1` …). |
| 足部压力 | Draft title unit: Pa. File: `draw1.js`. |
| 皮下组织厚度 | Draft series unit: mm, with a difference series labeled `um`. File: `draw2.js`. |

## Unit traps

1. **Shoe length vs shoe size.** The scatter tooltip says `鞋码：… cm`.
   Do not convert those y-values as if they were EU sizes.
2. **Radar vs bar chart.** The same Chinese word (脚长, 鞋码, 身高) can
   mean raw centimeters on one panel and a 0–100 index on another.
3. **Difference series in `draw2.js`.** The line is labeled `差值:um`
   while the bars are millimeters. The stored integers (3–45) are
   whatever the draft file contains; they are not recomputed from the
   two bar series (`(diabetic - typical) * 1000` would be hundreds of
   micrometers, not these values).
4. **Plumpness index.** Documented as labeled. Not reinterpreted.
