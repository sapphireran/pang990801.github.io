# Extracted personal datasets

These files are copied out of the personal children’s foot-shape dashboard so the series can be read without opening the original ECharts IIFEs.

Nothing here is company data. The numbers are the same literals already committed in `js/index.js`, `draw1.js`, and `draw2.js`.

## How the files were built

```bash
python3 scripts/extract-personal-datasets.py
```

Re-run the script after editing those three JavaScript files. Do not hand-edit the generated JSON or CSV unless you also change the extractor.

## Quick facts from `summary.json`

- Female scatter: n = 199, height 79.73–152.78 cm, shoe 10.08–24.21 cm, *r* = 0.9135.  
  `shoe ≈ 0.1409 × height + 0.299`
- Male scatter: n = 199, height 75.48–149.96 cm, shoe 9.74–24.40 cm, *r* = 0.9156.  
  `shoe ≈ 0.1433 × height − 0.065`
- Pooled *r* = 0.9157 on 398 points.
- Mean foot length: girls longer at ages 6–10, boys longer at 11–14.
- Ring charts: “thin foot” 50 / 230 = **21.74%**, “thick foot” 435 / 2835 = **15.34%**.
- Same-size feet in the generated symmetry series: **62.86% → 90.91%** from age 2 to 14.
- All 14 `draw2.js` “差值:um” points **disagree** with `(diabetic − typical) × 1000`. The line is a third series, not a computed residual.

## Units to keep straight

| Series | Axis label in the UI | How to read it |
| --- | --- | --- |
| Height × shoe | both `cm` | Scatter `value[1]` is labeled 鞋码 but formatted as centimetres of length |
| Age × foot length | `cm` | Means, not raw children |
| BMI × 胖瘦度 | `脚长/脚宽` | Stored values are ~23–30, so they are not a physical length/width ratio |
| Radar | 0–100 | Display ranks. `12岁` shoe/foot cells are written as `77-6` and `79-8` |
| Symmetry | counts | Generated by `Math.log` (natural log) |
| `draw1.js` | Pa | Unmounted sketch |
| `draw2.js` | mm and “um” | Unmounted sketch; the um line is not the mm delta |

## Using the files from a lab page

Serve the **repository root** so `/data/*.json` resolves:

```bash
python3 -m http.server 4173
```

Then:

```js
const pack = await fetch("/data/height-shoe.json").then((r) => r.json());
console.log(pack.summary.pooled.pearson_r);
```

CSV is for spreadsheets. JSON is what the lab pages load.
