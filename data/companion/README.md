# Companion datasets

Personal teaching extracts from this GitHub Pages project. Regenerated by:

```bash
python3 scripts/extract-companion-data.py
```

Nothing here is a clinical table, a sizing standard, or a diabetic-foot study. The live dashboard embeds the same numbers in `js/index.js`. The two leftover sketches (`draw1.js`, `draw2.js`) are kept so the companion studio can talk about what was *not* mounted.

| File | What it holds |
| --- | --- |
| `catalog.json` | Series list, units, and honesty notes |
| `height-shoe.json` | 199 + 199 height × plotted shoe-length points |
| `age-foot-length.json` | Mean foot length, ages 6–14 |
| `bmi-shape.json` | BMI 12–24 vs the plotted plumpness index |
| `symmetry.json` | Age 2–14 pie counts from the `Math.log` generator |
| `radar.json` | Ages 9–12 display scores (0–100) |
| `leftovers.json` | Unmounted pressure / thickness sketches |
| `stats.json` | Pearson *r*, OLS, crossover age, ring percents |
| `workbook-answers.json` | Short key used by the reading workbook |

`examples/js/companion-data.js` is the same payload as a browser global (`window.COMPANION_DATA`).
