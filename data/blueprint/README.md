# Blueprint workshop datasets

Personal extracts from the 2020 children’s foot-shape dashboard on this
GitHub Pages site. Every coordinate already lived in `js/index.js`,
`draw1.js`, or `draw2.js`. The build step only rearranges those numbers
and adds summaries (OLS, height bins, size-system tables).

Rebuild from the repository root:

```bash
python3 scripts/build-blueprint-data.py
```

`payload.js` is the same object as `payload.json`, written for classic
`<script>` tags so the example pages do not need a bundler.

## What each file is

| File | Contents |
| --- | --- |
| `catalog.json` | Counts, source paths, personal-use disclaimer |
| `stats.json` | Girl/boy OLS, crossover age, BMI-index *r*, size formulas |
| `height-shoe.json` | 199 + 199 height–shoe-length points (centimetres) |
| `residuals.json` | Residual (cm) of each point against its sex-specific line |
| `height-bins.json` | 5 cm height bins with shoe-length percentiles |
| `age-foot-length.json` | Ages 6–14 means, girl−boy difference, first differences |
| `bmi-shape.json` | Thirteen BMI ticks vs the dashboard “胖瘦度” index |
| `symmetry.json` | Timeline pie counts reproduced from the original formula |
| `radar.json` | Ages 9–12, seven 0–100 scores (not millimetres) |
| `plantar-pressure.json` | Leftover `draw1.js` seven-site pressures |
| `tissue-thickness.json` | Leftover `draw2.js` fourteen-site millimetres |
| `size-table.json` | 140–240 mm feet → Mondopoint / 号 / EU / UK / US kids |
| `vignettes.json` | Eight teaching cases picked from real scatter points |
| `payload.json` / `payload.js` | All of the above in one object |

## Units that are easy to misread

- Dashboard **鞋码** is labelled in **centimetres of length**. It is not a
  retail 28 / 29 pair mark.
- Radar axes are **0–100 scores**. They are not raw girths.
- Left/right “counts” are **generated by a log formula** in `js/index.js`.
- The leftover thickness line is labelled **µm** but the numbers follow
  **tenths of a millimetre**. `tissue-thickness.json` keeps both.

These files are personal study material. They are not a sampling frame
and not a last-making spec.
