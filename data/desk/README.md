# Night Desk data

Personal reprint of the series already hardcoded in this 2020 GitHub Pages dashboard. The files are generated by `scripts/extract-desk.py`. They are not new measurements.

| File | What it mirrors |
| --- | --- |
| `height-shoe.json` | 199 female + 199 male height / labeled-shoe-size points from `js/index.js` |
| `age-foot-length.json` | Mean foot length by age 6–14 |
| `bmi-ratio.json` | BMI slices plus the two decorative rings |
| `symmetry.json` | Left/right pie shares from the `ln(i+1)` formula |
| `radar.json` | Ages 9–12 on the seven-axis radar, with `77-6` / `79-8` already evaluated |
| `plantar-pressure.json` | Unused `draw1.js` adult contrast |
| `tissue-thickness.json` | Unused `draw2.js` adult contrast |
| `stats.json` | OLS fits, residual bins, crossover age, pie shares |
| `clinic.json` | Cards for common misreads |
| `payload.js` | One `window.DESK_DATA` blob so example pages can boot without `fetch` |
| `catalog.json` | SHA-256 of the source scripts and row counts |

Do not treat these numbers as a last specification, a sizing standard, or a clinical result. See `docs/desk/clinic.html`.
