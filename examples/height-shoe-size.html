How to read it

The mass is a diagonal band, not a single rule. At a fixed stature the last length still spreads several centimetres. Bounding boxes on the homepage make each sex look rectangular; this page leaves them off so the band is easier to see.

What the file actually stores

199 + 199 pairs of [height_cm, shoe_length_cm]. Girl means sit a little higher (116.86 / 16.76) than boy means (111.82 / 15.96). That is this sketch, not a population table.
