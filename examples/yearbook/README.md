# Field yearbook examples

Personal reconstructions of the 2020 children’s foot-shape charts.
They read `data/yearbook/payload.js` and the leftover files already in
this repository. They do not change the live homepage.

| Page | What it does |
| --- | --- |
| [index.html](index.html) | Desk index |
| [scatter-desk.html](scatter-desk.html) | Height–shoe scatter with sex filter and OLS |
| [growth-folio.html](growth-folio.html) | Ages 6–14 foot-length story |
| [bmi-bench.html](bmi-bench.html) | BMI vs length/width lines |
| [symmetry-reel.html](symmetry-reel.html) | Pauseable 2–14 symmetry bins |
| [radar-portraits.html](radar-portraits.html) | 9–12 relative profiles |
| [leftover-annex.html](leftover-annex.html) | Pressure and thickness leftovers |
| [map-annex.html](map-annex.html) | Unused China flight-line sketch |
| [print-folio.html](print-folio.html) | One-page print / PDF sheet |

Serve from the repo root:

```
python3 -m http.server 4173
```
