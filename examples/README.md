# Examples

Seven standalone charts extracted from the personal foot-shape dashboard.

Open [index.html](index.html) on GitHub Pages or via a static server. Each page loads `../js/echarts.min.js`, a shared theme helper, one chart module, and JSON from `data/`.

| File | Question |
| --- | --- |
| `height-shoe.html` | How does stature sit next to shoe length for girls vs boys? |
| `age-foot-length.html` | How does mean foot length move from 6 to 14, and when does the gap flip? |
| `growth-radar.html` | How do seven relative scores stack at ages 9–12? |
| `bmi-foot-shape.html` | What does the dashboard plot against BMI 12–24? |
| `foot-symmetry.html` | How does the illustrated left/right mix change with age? |
| `plantar-pressure.html` | What did `draw1.js` do with seven pressure sites? |
| `tissue-thickness.html` | What did `draw2.js` do with fourteen thickness sites? |

See `../docs/examples-guide.md` for the file contract and `../docs/measurement-notes.md` before quoting a number.
